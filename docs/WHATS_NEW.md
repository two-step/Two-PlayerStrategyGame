# What's new — PuzzleStow v1.0.1

Первый релиз, собранный автоматикой. Что вошло (в порядке значимости для игры).

## Правила погрузки: канон ходьбы (WALK)

Грузчик теперь ходит по контейнеру по физическим правилам, а не по упрощённой модели:

- **WALK** — подъём до 3 ячеек с грузом, спуск до 3 пешком; выше/глубже — непроходимо;
  вход никогда не начинается с ямы.
- **BEND (наклон)** — только вниз. Стоя на кромке, грузчик опускает фигуру не глубже
  3 ячеек по полке; остальную высоту до опоры закрывает сама фигура.

## Система троек (репорт 16)

Наклон измеряется тремя тройками: подъём 3 / спуск 3 / свисание 3. Свисание =
(ступни − контактная высота) − размах фигуры ≤ 3. Путь груза от точки захвата до
каждого сиденья — путь только вниз или горизонтально по пустому воздуху: стены нельзя
ни пробить, ни перелезть сверху. Случай 06B10A11 (F06 в колодце 5×2) теперь легален,
«клюшка» F09 через стену — по-прежнему нет.

## Fair play

- Вердикт показывается **в момент фиксации** заявки, а не после подтверждения.
- Кнопка **«Order fair play»** — заказ разбора у судьи прямо из игры.
- Пороги по сложности: easy 75 % / medium 65 % / hard 55 %.

## Сайт

- **Музыка (TO_DO 29):** настоящий переключатель с треками Suno, состояние сохраняется.
- **Новости (TO_DO 33):** новостная лента-тикер на главной; контент в Supabase
  (публичная миграция чтения), редактируется без передеплоя.
- Локализация интерфейса дополнена ключами для тикера и музыки.

## Движок соперника

- **Философия досягаемости:** движок ценит newly reachable cells (прирост ×2 в критической
  зоне) наравне с потерей территории — строит лестницы перед стенами и засыпает глубокие
  ямы до ≤3.
- **«Только-моно» клетки — практически мёртвые:** проход шириной 1 не считается живой
  вакансией при оценке достройки ряда.
- **Дисциплина потолка и входа:** без нужды не пихает фигуры в ряды J/K и колонку 0
  (штраф, отменяется, если ход закрывает ряд).
- Движок теперь автоматически фильтрует ходы по всему канону ходьбы — ставит только то,
  что физически может сделать грузчик.
